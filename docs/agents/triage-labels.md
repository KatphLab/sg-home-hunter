# Triage Labels

The engineering skills use five canonical triage roles. For local Markdown issues, record the corresponding string in the issue's `Status:` line.

| Canonical role    | Tracker status    | Meaning                                  |
| ----------------- | ----------------- | ---------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate this issue  |
| `needs-info`      | `needs-info`      | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent  |
| `ready-for-human` | `ready-for-human` | Requires human implementation            |
| `wontfix`         | `wontfix`         | Will not be actioned                     |

When a skill mentions a role, use its tracker status from this table. Edit the tracker-status column to change the vocabulary.
